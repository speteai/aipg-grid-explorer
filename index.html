Image generation

POST /v1/images/generations is live and OpenAI-compatible, but the image models are not returned by /v1/models — they can only be discovered from an error string. The list below was captured on 2026-11-05; use the key probe to refresh it live.

ParameterBehaviour
modelRequired (unlike text, "auto" is rejected). Omitting it defaults to FLUX.2 Klein 4B FP8.
sizeValidated: width & height each 512–1536. 256x256 → 422.
nSupported; returns N images.
response_formaturl (served from media.aipg.art) or b64_json.
responseEach item has revised_prompt, seed; a top-level grid block has job_id, worker, gen_time, model.

Live key probe optional

Paste a grid_… API key to live-refresh the image-model list and show your linked account. The key stays only in this browser (localStorage), is sent only to api.aipowergrid.io, and is never uploaded anywhere else.

Developer gotchas

Things that cost us time while integrating — documented so they don't cost you any.

⚠
Default Python-urllib User-Agent is blocked (403). A request with no custom User-Agent gets a blank 403 before auth is even checked. Set any UA (the official OpenAI/Anthropic SDKs and curl already do). See examples below.
◆
Reasoning models can return content: null. qwen3:* and gpt-oss-120b spend the token budget on hidden reasoning; at small max_tokens you get finish_reason:"length" and empty content. Give generous headroom (≥ ~1024 even for trivial prompts).
◆
Balance lives at /v1/account/credits. Read total_spendable_usd there before you call, instead of discovering a 402 mid-request. The full endpoint list is public at /openapi.json (Swagger UI at /docs).
◆
Legacy /api/v2 (AI-Horde style) is retired — returns 410 Gone, pointing at /v1.
◆
Not available (all 404): /v1/embeddings, /v1/completions, /v1/audio/*, /v1/moderations, /v1/rerank. Don't assume full OpenAI parity.

Quickstart

Base URL https://api.aipowergrid.io/v1 · OpenAI-compatible · remember the User-Agent.

curl https://api.aipowergrid.io/v1/chat/completions \
  -H "Authorization: Bearer $AIPG_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4-flash-nvfp4",
    "messages": [{"role":"user","content":"Hello!"}],
    "max_tokens": 256
  }'
from openai import OpenAI  # official SDK sets its own User-Agent

client = OpenAI(base_url="https://api.aipowergrid.io/v1",
                api_key="grid_...")

r = client.chat.completions.create(
    model="deepseek-v4-flash-nvfp4",
    messages=[{"role": "user", "content": "Hello!"}],
    max_tokens=256,          # for qwen3:* / gpt-oss-120b use >= 1024
)
print(r.choices[0].message.content)

# Raw urllib/requests? You MUST set a User-Agent or you get 403:
#   headers["User-Agent"] = "my-app/1.0"
const r = await fetch("https://api.aipowergrid.io/v1/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${AIPG_KEY}`,
    "Content-Type": "application/json",
    "User-Agent": "my-app/1.0"            // browsers set this for you
  },
  body: JSON.stringify({
    model: "deepseek-v4-flash-nvfp4",
    messages: [{ role: "user", content: "Hello!" }],
    max_tokens: 256
  })
});
console.log((await r.json()).choices[0].message.content);
curl https://api.aipowergrid.io/v1/images/generations \
  -H "Authorization: Bearer $AIPG_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "z-image-turbo",
    "prompt": "a single red circle on a white background",
    "size": "512x512",
    "n": 1
  }'
# -> data[].url (media.aipg.art) + seed; model is REQUIRED (no "auto")

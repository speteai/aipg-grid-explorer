Developers

Base URL https://api.aipowergrid.io/v1, OpenAI-compatible. The full endpoint list is public at /openapi.json (Swagger UI at /docs).

Things that cost integration time

The default Python-urllib User-Agent is blocked (403). A request with no custom User-Agent gets a blank 403 before the key is even checked. Set any User-Agent; the official OpenAI and Anthropic SDKs and curl already do.
Reasoning models can return content: null. qwen3:* and gpt-oss-120b spend the token budget on hidden reasoning. With a small max_tokens you get finish_reason: "length" and no answer. Give at least about 1024, even for trivial prompts.
Reasoning effort: only low and medium pass. The grid turns none and minimal into low and drops other values, so the serving machine applies its default.
The balance lives at /v1/account/credits. Read total_spendable_usd before you call instead of meeting a 402 mid-request. POST /v1/account/credits/quote estimates a request in advance.
The daily free allowance needs a Google sign-in. It is granted only to accounts with a verified Google sign-in; other accounts see it but cannot spend it.
Sign-in without an API key exists. The grid is an OAuth 2.1 server for public clients (PKCE, loopback redirect for native apps). Access tokens last 15 minutes; with the offline_access scope you get a rotating refresh token. Metadata: /.well-known/oauth-authorization-server.
The legacy /api/v2 (AI-Horde style) is retired. It returns 410 Gone and points at /v1.
Not available (all 404): /v1/embeddings, /v1/completions, /v1/audio/*, /v1/moderations, /v1/rerank. Do not assume full OpenAI parity.

Quickstart

curl https://api.aipowergrid.io/v1/chat/completions \
  -H "Authorization: Bearer $AIPG_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "auto",
    "messages": [{"role":"user","content":"Hello!"}],
    "max_tokens": 1024
  }'
from openai import OpenAI  # the official SDK sets its own User-Agent

client = OpenAI(base_url="https://api.aipowergrid.io/v1",
                api_key="grid_...")

r = client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "Hello!"}],
    max_tokens=1024,         # reasoning models need the headroom
)
print(r.choices[0].message.content)

# Raw urllib/requests? You MUST set a User-Agent or you get 403:
#   headers["User-Agent"] = "my-app/1.0"
const r = await fetch("https://api.aipowergrid.io/v1/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${AIPG_KEY}`,
    "Content-Type": "application/json",
    "User-Agent": "my-app/1.0"            // browsers set this for you
  },
  body: JSON.stringify({
    model: "auto",
    messages: [{ role: "user", content: "Hello!" }],
    max_tokens: 1024
  })
});
console.log((await r.json()).choices[0].message.content);
curl https://api.aipowergrid.io/v1/images/generations \
  -H "Authorization: Bearer $AIPG_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "z-image-turbo",
    "prompt": "a single red circle on a white background",
    "size": "1024x1024",
    "n": 1
  }'
# -> data[].url (media.aipg.art) + seed; model is REQUIRED (no "auto")

Image generation parameters

ParameterBehaviour
modelRequired. Unlike text, "auto" is rejected.
sizeWidth and height each 512–1536. 256x256 gives 422.
nSupported; returns N images.
response_formaturl (served from media.aipg.art) or b64_json.
responseEach item has revised_prompt and seed; a top-level grid block has job_id, worker, gen_time, model.
